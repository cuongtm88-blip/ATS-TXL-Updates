# ATS TXL Updates

Kênh phát hành công khai dành cho chức năng tự cập nhật **ATS TXL trên Windows**.

Mỗi bản phát hành hợp lệ gồm đúng hai tài sản:

- `ATS-TXL.exe`: ứng dụng Windows đã đóng gói.
- `ATS-TXL.exe.sha256`: mã SHA-256 để ứng dụng xác minh file tải về.

Mã nguồn, Telegram Bot token, Chat ID và `settings.json` không được lưu trong
repository này. Cấu hình người dùng được giữ cục bộ trên từng máy khi EXE được
cập nhật.

Xem bản mới nhất tại [Releases](../../releases/latest).
