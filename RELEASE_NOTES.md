## Nội dung cập nhật 1.0.2

- Sửa lỗi khởi động `Failed to load Python DLL ... python312.dll` sau khi cập nhật trên một số máy Windows.
- Bản Windows được đóng gói bằng Python 3.11 để tăng khả năng tương thích.
- GitHub Actions tự chạy kiểm tra khởi động EXE trước khi phát hành.

Trước mỗi lần phát hành tiếp theo, hãy sửa nội dung tệp này và tăng `APP_VERSION` trong `version.py`.
